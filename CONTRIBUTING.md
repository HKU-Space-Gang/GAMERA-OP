# Contributing to GAMERA-OP
Thank you for your interest in GAMERA-OP. Please follow these guidelines to help maintain our 
research environment.

## No Development Support
This is a research-only public release. The maintainers do not provide support for local environment 
setup or personalized guidance on new physics implementation. 

## Code of Conduct
All contributors should adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).

## Git Etiquette
Do not commit any large files (>10MB) unless absolutely necessary. Always check git status before 
committing and use git rebase to maintain a clean history.

## Licensing
By contributing, you agree that your code will be released under the project's current open-source license.
